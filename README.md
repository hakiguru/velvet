# Velvet Lite

NPC mod for Minecraft 1.21.1 (NeoForge). Adds Elsie, a companion NPC with commands, inventory, armor and skill levels.

**18+: the mod contains adult content.**

## Requirements
- Minecraft 1.21.1, NeoForge 21.1.x
- GeckoLib 4.7+

## Build
```
cd velvet-lite-neoforge-1.21.1
./gradlew build
```
The jar is written to `velvet-lite-neoforge-1.21.1/build/libs/`.
